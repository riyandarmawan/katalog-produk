# Aplikasi Katalog Produk

Aplikasi berbasis desktop untuk mengelola inventaris produk makanan dan minuman (mencatat, melihat, mengedit, dan menghapus data).

## Prerequisites

- Java Development Kit (JDK)
- NetBeans IDE

## Cara Menjalankan Project

1. **Clone project:** `https://github.com/riyandarmawan/katalog-produk.git`
2. **Buka NetBeans IDE**
3. **Open project:** Pilih **File** > **Open Project...**, arahkan ke folder project, lalu klik **Open Project**.
4. **Jalankan Program:** Klik kanan pada project `katalogProduk` dan pilih **Run**.

## Fitur Utama

- **Katalog Produk:** Menampilkan daftar produk secara visual dalam bentuk kartu (*card*) yang memuat gambar, nama, harga, dan ID produk.
- **Tambah Produk:** Input data produk baru dengan mengisi nama produk, harga (Rp), serta memilih foto contoh dari pilihan yang tersedia.
- **Ubah/Edit Produk:** Memperbarui informasi produk yang sudah ada secara langsung melalui form interaktif.
- **Hapus Produk:** Menghapus data produk dari katalog dengan sistem konfirmasi keamanan (*dialog confirmation*).
- **Informasi Jumlah Produk:** Menampilkan total jumlah produk secara *real-time*.
